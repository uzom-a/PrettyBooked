# PrettyBooked

A campus beauty and style booking app for ladies at Grambling State University.

## Tech Stack
- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Supabase (Auth, Database, Storage)

## Features
- Browse service providers by category (braiders, nail techs, lash techs, seamstresses, etc.)
- Book appointments with providers
- Message providers directly
- Leave reviews and ratings
- Admin approval queue for new providers

## Getting Started

```bash
npm install
npm run dev
```
